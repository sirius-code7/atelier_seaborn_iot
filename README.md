# Atelier Seaborn

Seaborn est une bibliothèque de visualisation de données en Python construite au-dessus de Matplotlib.
## Structure

```
atelier_seaborn_iot/
│
├── data/
├── notebooks/
└── exports/
```

Le projet est organisé en plusieurs dossiers afin de séparer les données, le notebook de travail et les graphiques exportés.

Cette organisation facilite le développement, la maintenance et la réutilisation du projet.
